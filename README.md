# 口袋單字卡

Android 12 以上的單字卡 App。桌面小工具可上下滑動換卡，點一下卡片顯示釋義，再點一次收起。

## 使用方式

1. 安裝 APK 後開啟「口袋單字卡」。App 內有一組工程英文範例可試用。
2. 點牌組名稱進入單字清單，可以新增、搜尋或編輯單字卡。長按牌組可進入多選，從右上角選單編輯、合併或刪除。
3. 點牌組右側的播放鍵。單字卡模式可上下滑動換卡，點一下翻面。英中對照模式會同時顯示上下兩張卡，例句在下方的釋義卡。
4. 從左上角主選單進入「桌面小工具」，選擇牌組後按「加到手機桌面」。也可以長按手機桌面空白處，從「小工具」選擇「口袋單字卡」。
5. 點桌面小工具左上的牌組名稱可切換牌組。上下滑動換卡，點一下看釋義。若顯示範圍超過 100 張，可用組別按鈕切換下一組。

兩種複習模式都可切換待複習與全部練習。答「還不熟」的卡 10 分鐘後到期。連續答「記住了」的卡依序隔 1、3、7、14、30 天到期。滑動或按上一張、下一張只會換卡。小工具可快速瀏覽，複習評分在 App 裡進行。

合併時先選要保留的牌組。其他牌組的卡片與複習進度會移入該牌組，發音語言採用保留牌組的設定。

單字與複習進度儲存在手機上。發音使用手機已安裝的離線文字轉語音，牌組可設定英文、日文或中文。多個桌面小工具使用同一個顯示牌組設定。

## 開發

用 Android Studio 開啟這個資料夾，安裝 Android SDK Platform 35 和 SDK Build Tools 35.0.0，使用 JDK 17 執行：

```sh
./gradlew assembleDebug
```

輸出位於 `app/build/outputs/apk/debug/app-debug.apk`。Windows 可使用 `gradlew.bat assembleDebug`。覆蓋安裝同套件名稱的既有版本時，APK 必須使用相同簽章。

App 以 Java、SQLite 和 Android SDK 編寫。桌面元件使用 `AppWidgetProvider`、`RemoteViews.RemoteCollectionItems` 與 `StackView`。
